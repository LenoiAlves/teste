# Serviço Streaming Gratuito 

plataforma digital que busca ser uma alternativa sem fins lucrativos ou infração de direitos autorais de diversas obras

*Organização* 

1. A plataforma irá separar os filmes, series, desenhos e animes em difentes classes de acordo com o genêro da obra
2. diferentes formatos estarão mais separados. Filmes terão sua própria aba , assim como séries, animes  e desenhos
3.  haverá uma opção de salvar uma biblioteca do site para assim não haver necessidade de manter varias aba do navegador aberto

*Anúncios*

apenas anúncios permitidos serão presentes no site para manté-lo de pé, somente enquanto o Site não é monetizado e se  tornar uma opção viável para as pessoas sem condições de pagar o streaming de empresas conhecidas.
## Finalidade do programa
1. Alternativa gratuita de streaming de diversos tipos
2. Solução para pessoas com condições insuficientes para manter outros serviços
3. Agradar as mais variáveis faixas etárias com o objetivo de entreterimento de diversos genêros
