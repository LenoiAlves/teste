# Serviço Streaming Gratuito 

plataforma digital que busca ser uma alternativa sem fins lucrativos ou infração de direitos autorais de diversas obras

#Organização 

1. A plataforma irá separar os filmes, series em difentes classes de acordo com o genêro da obra
2. diferentes formatos estarão mais separados. Filmes terão sua própria aba , assim como séries e filmes
3.  haverá uma opção de salvar uma biblioteca do site para assim não haver necessidade de manter varias aba do navegador aberto
